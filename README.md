Constructor Assignment
This is a basic console application project designed to demonstrate the use of different variable types and the constructor chaining technique in C#.

Skills Demonstrated:

Declaration and usage of const variables (compile-time constants).

Declaration and usage of var variables (type inference).

Implementation of constructor chaining for code reuse within a class.

Basic principles of Object-Oriented Programming (classes, properties, constructors).

Try/Catch Assignment
A console application focused on robust error handling using try-catch blocks. The application prompts the user for their age and calculates their birth year, managing various input exceptions.

Skills Demonstrated:

Implementation of try-catch blocks for exception handling.

Handling specific exceptions (FormatException, ArgumentOutOfRangeException).

Implementation of a finally block for cleanup code.

User input validation.

Basic DateTime operations.

Car Insurance Web Application
A full MVC web application developed with ASP.NET Core and Entity Framework Core. This application simulates a car insurance quotation system, allowing users to register, get a quote based on business rules, and administrators to view all issued quotes.

Skills Demonstrated:

Web application development using the MVC (Model-View-Controller) pattern.

Data persistence with Entity Framework Core (Code-First).

Defining data models and mapping to a SQL Server database.

Using Entity Framework Migrations for database schema management.

Implementing CRUD (Create, Read, Update, Delete) operations.

Developing complex business logic (quote calculation).

Using Razor Syntax to combine C# and HTML in views.

Application configuration and connection strings in appsettings.json.

Scaffolding controllers and views in Visual Studio.

Final Challenge: Code-First Console Application
A console application project demonstrating Entity Framework Code-First's ability to create a database and its tables from C# models, and then interact with it to add and retrieve data.

Skills Demonstrated:

Configuring Entity Framework Core in a console application.

Defining a DbContext and a simple data model.

Using Add-Migration and Update-Database to create and update the database.

Reading connection strings from appsettings.json in a console application.

Inserting and querying data in a database using Entity Framework.

Handling design-time database context creation (IDesignTimeDbContextFactory).

Object-Oriented Programming (OOP) in C#: Classes, objects, properties, methods, constructors, inheritance (implicit in EF Core).

Exception Handling: Using try-catch-finally to build robust applications.

Web Development with ASP.NET Core MVC: Deep understanding of the MVC pattern, routing, controllers, Razor views, and models.

Data Access with Entity Framework Core: Code-First database modeling, migrations, LINQ for queries, CRUD operations.

Application Configuration: Managing configurations (e.g., connection strings) in appsettings.json.

Development Tools: Effective use of Visual Studio (NuGet Package Manager, Package Manager Console, Scaffolding, Hot Reload).

Version Control: Managing source code with Git and GitHub (commits, push).

Database Concepts: Understanding the interaction between applications and SQL databases.
